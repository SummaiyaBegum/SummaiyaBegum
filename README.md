## 🌱 My Learning Approach

Coming from a Life Sciences and Microbiology background, I'm learning bioinformatics step by step.

I don't want to simply copy commands from tutorials. I want to understand what I'm doing and why.

For each project, I'm trying to follow this approach:

```text
Understand the biological question
              ↓
Understand the data
              ↓
Choose the appropriate tools
              ↓
Run the analysis
              ↓
Interpret the results
              ↓
Validate the outputs
              ↓
Document the workflow
              ↓
Make it reproducible
